# ChatUSB 自建中央服务器

ChatUSB 默认使用公共消息中转（emqx / hivemq）。如果你想让聊天走**你自己的服务器**，用这个目录里的服务端即可。

## 一、运行（需要一台能常开的机器）
任选一台：家里的电脑 / 云服务器 / 群晖 / 树莓派等，只要装 Node.js（≥16）即可。

```
cd server
npm install
node server.js
```

看到 `自建中央服务器已启动` 就是好了。**这台机器需要保持开机**，聊天才能经过它。

## 二、客户端怎么连
打开 ChatUSB → **⚙ 设置** → **公共消息服务地址**，填入服务器地址，保存即可（之后会自动连你的服务器，替代公共中转）。

| 场景 | 填写的地址 |
|---|---|
| 同一局域网（家里） | `ws://服务器内网IP:3722/mqtt`，例如 `ws://192.168.1.100:3722/mqtt` |
| 公网（云服务器，无加密） | `ws://你的公网IP:3722/mqtt`（需防火墙放行 3722） |
| 公网（有域名+HTTPS证书） | `wss://你的域名:3723/mqtt`（见下文 HTTPS 配置） |

## 三、账号中心（全局唯一账号）
启动本服务器后，在客户端 **⚙ 设置 → 账号服务器地址** 填 `http://你的IP:3722`。之后所有设备用同一 QQ 邮箱/手机号注册/登录，就是**同一个账号**（服务器只存加盐密码哈希，不存明文）。服务器不可达时，客户端自动回退本地账号，不影响使用。

## 四、HTTPS（公网加密，可选）
如果你有域名和证书，设置环境变量后启动：
```
set TLS_CERT=C:\路径\fullchain.pem
set TLS_KEY=C:\路径\privkey.pem
node server.js
```
服务器会同时监听 3722（明文）和 3723（加密）。

## 五、说明与边界（重要）
- 这台服务器只负责**消息中转（broker）+ 账号中心**，不保存聊天内容——消息仍是端到端加密（房间密码），服务器也解不开。
- 好友关系仍存在各端本地；一对一私聊不依赖这台服务器，用公共中转也能用。
- 防火墙/端口：云服务器需在安全组放行 3722（及 3723）。
